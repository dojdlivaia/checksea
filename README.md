# 🌊 Морской чек-лист Макади

Интерактивный чек-лист для юных исследователей (7–10 лет), отдыхающих в бухте Макади (Египет, Красное море). Ребёнок отмечает увиденных рыб, кораллы и морских обитателей, разблокирует ачивки и делится результатом.

![Палитра](https://img.shields.io/badge/бирюза-0FB3C4?style=flat-square) ![Палитра](https://img.shields.io/badge/коралл-FF6B6B?style=flat-square) ![Палитра](https://img.shields.io/badge/солнечный-FFD93D?style=flat-square)

## ✨ Возможности

- 📋 **Чек-лист** — 50+ морских обитателей с реальными фото, фактами и категориями
- 📸 **Галерея фотографий** — 2-3 ракурса на каждое существо, поддержка свайпа
- 🏆 **Ачивки** — 7 достижений с тост-уведомлениями при разблокировке
- 🎯 **Челленджи** — особые задания (радуга тридакны, вечеринка губанов, семейство клоунов и др.)
- 🎨 **Мультяшные SVG-иконки** — детализированные иконки для страницы достижений
- 🎓 **Сертификат** — генерация PNG через Canvas с именем ребёнка
- 📤 **Шеринг** — Web Share API на мобильных, буфер обмена на десктопе
- 💾 **Сохранение** — всё хранится в localStorage
- 📱 **Mobile-first** — работает от 320px до десктопа
- 🎨 **Анимации** — пузыри, покачивание, bounce, конфетти

## 🚀 Как развернуть на GitHub Pages

### Шаг 1: Создайте репозиторий

1. Зайдите на [github.com](https://github.com) → **New repository**
2. Назовите, например: `makadi-checklist`
3. Выберите **Public**
4. Нажмите **Create repository**

### Шаг 2: Загрузите код

```bash
# Клонируйте или создайте локально
git init
git add .
git commit -m "🌊 Морской чек-лист Макади"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/makadi-checklist.git
git push -u origin main
```

### Шаг 3: Включите GitHub Pages (АВТОМАТИЧЕСКИЙ ДЕПЛОЙ)

Workflow уже создан в `.github/workflows/deploy.yml`! Просто:

1. Зайдите в **Settings** → **Pages**
2. В разделе **Source** выберите:
   - Source: **GitHub Actions**
3. Сохраните

После push в main, сайт автоматически соберётся и задеплоится.

Сайт будет доступен по адресу:
`https://ВАШ_ЛОГИН.github.io/makadi-checklist/`

### Шаг 4: Откройте сайт

Перейдите по ссылке: `https://ВАШ_ЛОГИН.github.io/makadi-checklist/`

⚠️ **Если белая страница:**
1. Подождите 2-3 минуты после первого push
2. Откройте DevTools (F12) → Console — проверьте ошибки
3. Убедитесь что в Settings → Pages выбрано "GitHub Actions" как Source
4. Проверьте что Actions → Workflow завершился успешно (зелёная галочка)
5. Попробуйте открыть в режиме инкогнито (кэш)

На телефоне: откройте сайт → «Добавить на главный экран» для PWA-режима.

## 🐠 Как добавить новых обитателей

Откройте `src/data/creatures.ts` и добавьте в массив:

```typescript
{
  id: 'unique-id',           // Уникальный идентификатор
  name: 'Название',          // На русском
  emoji: '🐡',              // Эмодзи
  images: [                  // Массив URL фотографий (2-3 ракурса)
    'https://commons.wikimedia.org/wiki/Special:FilePath/photo1.jpg?width=600',
    'https://commons.wikimedia.org/wiki/Special:FilePath/photo2.jpg?width=600',
  ],
  fact: 'Короткий факт',    // 1 строка
  category: 'fish',          // fish | coral | other
  rare: false,               // true если редкий
}
```

Затем добавьте SVG-иконку в `src/components/CreatureIcons.tsx`.

## 🎯 Челленджи

Особые задания для продвинутых исследователей:

| Челлендж | Описание |
|----------|----------|
| 🌈 Радуга тридакны | Увидеть тридакну в 4 разных цветах (синяя, зелёная, фиолетовая, оранжевая) |
| 🎉 Вечеринка губанов | Встретить 5 разных губанов (синий, зелёный, жёлтый, красный + обычный) |
| 👨‍👩‍👧‍👦 Семейство клоунов | Найти всех рыб-клоунов (обычный, двухполосный, малыш) |
| 🦋 Коллекция бабочек | Собрать 4 рыбы-бабочки (бабочка, вымпельная, хромис, мавританский идол) |
| 🦕 Охотники за гигантами | Увидеть 3 гигантских существ (наполеон, тридакна, черепаха) |
